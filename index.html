Championship Math uses each series' real points-per-finish table (NASCAR's is simplified to finishing position only — it ignores stage points and race-win playoff bonuses, so treat it as directional, not official). Every driver is checked against every other driver directly — their own ceiling (winning every remaining race) against each rival's floor (current points, since points only go up) — rather than assuming the standings leader is automatically the only threat; whoever clears every rival that way is Leader, everyone else is Alive or Eliminated by the same test. The headline number in each writeup is a points-per-race margin (current gap ÷ races remaining) — how much a trailing driver has to outscore a rival by, on average, to close it — which makes no assumption about the rival's own pace; it's true whether the rival goes cold or keeps winning, since only the gap between them matters. Underneath, a table compares that same margin across everyone still mathematically alive (all measured against the same leader), so it's easy to see who has the easier path — and a line calls out the closest driver behind, with the smaller margin it'd take for them to catch this driver specifically rather than the leader. Scenarios you build in the calculator are exact per-race sums for both drivers, not averages or assumptions.
